# BALI STOCK

Кроссплатформенное приложение складского учёта для ночного клуба BALI.

## Что уже реализовано

- Windows / Android / iOS из одной Flutter-кодовой базы.
- Категории: виски, ром, водка, коньяк/бренди, текила, ликёры, безалкогольные и другие; новые категории можно добавлять.
- Добавление новой позиции с обязательным выбором категории.
- Для каждой позиции задаются:
  - количество целых бутылок;
  - объём одной бутылки в мл (500, 700, 1000 или любое другое значение);
  - дополнительный остаток в мл;
  - минимальный допустимый остаток в мл.
- Отображение остатка в понятном виде: `5 бут. × 0,5 л + 250 мл`.
- Критический/нулевой остаток подсвечивается красным.
- Приёмка поставки с автоматическим увеличением текущего склада.
- Полный переучёт всего склада: нельзя провести, пока явно не заполнена каждая активная позиция.
- Нулевой остаток тоже вводится явно: `0 бутылок + 0 мл`.
- История всех поставок и переучётов доступна всем пользователям без пароля.
- Для входа в «Поставка» и «Переучёт» используется PIN, заданный владельцем проекта.
- История хранит `было → изменение/расхождение → стало`.

## Хранение данных

MVP использует локальную SQLite-базу на устройстве. Это надёжно для автономной работы, но данные разных телефонов/ПК пока не синхронизируются между собой. Для единого общего склада на нескольких устройствах следующим этапом нужен центральный backend/API.

## Первый запуск

Установите Flutter SDK, затем из корня репозитория выполните:

```bash
flutter create . --project-name bali_stock --org com.bali.stock --platforms=android,ios,windows
flutter pub get
flutter run
```

Команда `flutter create` создаёт стандартные платформенные оболочки Android, iOS и Windows, не меняя бизнес-логику приложения в `lib/`.

## Сборка

### Windows

```bash
flutter build windows --release
```

### Android

```bash
flutter build apk --release
```

### iOS

Сборка iOS выполняется на macOS с Xcode:

```bash
flutter build ios --release --no-codesign
```

Для установки на реальные iPhone потребуется настроить Apple signing / provisioning profile.

## Структура

- `lib/data/` — SQLite и операции склада.
- `lib/screens/` — склад, поставка, переучёт, история.
- `lib/widgets/` — общие UI-компоненты.
- `lib/security.dart` — локальная проверка PIN по хэшу.
- `lib/models.dart` — модели и форматирование остатков.

## Важно о PIN

PIN в локальном клиентском приложении является защитой от случайного/обычного доступа, но не полноценной серверной авторизацией. Для строгого разграничения прав на нескольких устройствах проверку нужно перенести на backend.
