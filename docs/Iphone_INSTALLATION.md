# BALI STOCK — установка на iPhone / iPad

Основной production-вариант для iPhone и iPad — профиль `BALI-STOCK-iPhone.mobileconfig`.

Профиль добавляет BALI STOCK на экран «Домой» как полноэкранный Web Clip и открывает стабильную HTTPS-страницу:

- адрес Web Clip не меняется между обновлениями;
- актуальная версия интерфейса публикуется по адресу `https://nik13599.github.io/BALI-STOCK/`;
- страница открывается напрямую, без `raw.githack`, HTML Blob и лишнего redirect, поэтому iOS может корректно запросить камеру;
- данные, синхронизация и операции продолжают работать через Supabase;
- пользовательский пароль/PIN для обычного запуска не требуется;
- нижняя навигация: «Главная → Склад → Переучёт → Закупки → Поставка → Настройки»;
- история операций находится внутри раздела «Настройки», отдельной нижней вкладки «История» нет.

## Установка Web Clip

1. Получите артефакт `BALI-STOCK-iPhone-WebClip` из production-сборки.
2. Откройте файл `BALI-STOCK-iPhone.mobileconfig` на iPhone/iPad.
3. В iOS откройте загруженный профиль и подтвердите установку.
4. Запустите появившийся значок `BALI STOCK` с экрана «Домой».

Профили версии 1.0.5 и ниже нужно один раз заменить профилем 1.0.6: адрес запуска изменён для исправления камеры. Затем повторная установка при обычных обновлениях не требуется.

## Сканер на iPhone

При первом запуске сканера разрешите доступ к камере. Если live-видео не запустилось из-за ограничения конкретной версии iOS/WebKit, нажмите «СФОТОГРАФИРОВАТЬ КОД»: откроется системная камера, а приложение распознает QR-код или штрихкод на снимке. Ручной ввод кода остаётся доступен.

## Если приложение зависло на «Подключение…»

Закройте Web Clip из переключателя приложений и откройте его снова. В production-коде есть резервное получение складского снимка через `bali-stock-client-api`, поэтому отсутствие базовой функции `snapshot()` не должно блокировать весь интерфейс.

## Native iOS build

Репозиторий также формирует нативный Flutter iOS build без подписи. Для установки `Runner.app`/`.ipa` на физическое устройство требуется Apple code signing: Apple Developer certificate + provisioning profile либо локальная подпись через Xcode.

Native build является дополнительным вариантом. Production Web Clip через `.mobileconfig` остается поддерживаемым способом установки BALI STOCK на iPhone/iPad.
